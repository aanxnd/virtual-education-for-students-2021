# Virtual Education for Students (VES)

An educational resources website I built for the TISB Hackathon in 2021.

VES was one of my earliest programming projects and was built from scratch using HTML, CSS, and vanilla JavaScript. The website provides educational material across mathematics, physics, chemistry, and biology through a collection of subject-specific pages and resources.

## Technologies

- HTML
- CSS
- JavaScript

## About This Repository

This repository contains the original project as it was built in 2021. It has been preserved as an archive of one of my first web development projects.
